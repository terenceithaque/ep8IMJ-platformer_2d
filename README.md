# Présentation
Ceci est un jeu de plateforme en 2D créé avec Godot dans le cadre du cours "Introduction aux moteurs de jeux" de la L1 informatique de Paris 8. Vous y incarnez un samuraï qui devra parcourir des niveaux tout en éliminant de nombreux ennemis sur son chemin.

L'ensemble du jeu est fait avec des outils open-source et des assets (images, sons, etc) libres de droit.
